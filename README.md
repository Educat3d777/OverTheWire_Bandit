## About This Project

I am an aspiring penetration tester working towards my first role in offensive cybersecurity, with a long-term interest in red teaming.

I am currently developing my skills through TryHackMe's certification pathway (SEC0 → SEC1 → PT1), alongside hands-on Linux challenges from OverTheWire Bandit.

This repository documents my learning journey, including the commands I use, my problem-solving approach, challenges I encounter, and the lessons I learn along the way.

My goal is to build a strong technical foundation, develop practical penetration testing skills, and demonstrate my progress through clear, structured documentation.
